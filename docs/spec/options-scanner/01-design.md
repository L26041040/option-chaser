## 0. 一分鐘看懂

使用者選一個範圍（例如「美國前 500 大公司」），系統自動做六件事：

1. **收集**每檔股票的分析師目標價與共識資料。
2. **排除**分析師太少、意見分歧太大、資料太舊的股票。
3. **預測**每檔股票在某個未來日期的「保守價格帶」，以及股價落在那個區間的**成真機率**。
4. **窮舉**這些股票在對應到期日的所有合格選擇權組合。
5. **計算**每個組合「如果股價落在價格帶內」的損益與報酬倍率。
6. **排序**，列出最有吸引力的機會。

整個系統分成兩半，用**一個交接物**接起來：

```
 ┌────────────────────────────┐   價格帶 Price Band   ┌────────────────────────────┐
 │ A. 預測（要研究的核心）     │ ───────────────────▶ │ B. 選擇權搜尋（機械化計算） │
 │ 分析師共識 → 價格帶＋機率   │  （標的、日期、下緣、  │ 窮舉 → 計算 → 過濾 → 排序   │
 │                            │    上緣、成真機率）    │                            │
 └────────────────────────────┘                       └────────────────────────────┘
```

- **A 是研究問題**：價格帶準不準、機率可不可信，需要歷史資料驗證。
- **B 是工程問題**：給定價格帶，算出每個組合的報酬是純計算，現有引擎大部分已經會做。

## 1. 產品目標（Owner 已確認）

| 項目 | 內容 |
|---|---|
| 產品 | 可自訂掃描範圍的選擇權機會搜尋器 |
| 最終範圍 | 自訂母體（如美國前 500 大）；未來擴充 ETF 與其他市場 |
| 研究期 | **允許縮小樣本驗證**；縮小的是研究樣本，不是產品目標 |
| 使用者優先拿到 | ① 高可信度價格帶 ② 價格帶成真機率 ③ 該價格範圍內的選擇權獲利表現 ④ 可比較的獲利倍率與排序 |
| 研究門檻 | 驗證的是**預測品質**；選擇權是否優於直接買股票只作參考，**不是**開發門檻 |

### 1.1 與現有產品的關係

現有的 **Scenario Bet Ranking** 回答「如果我的價格劇本成立，哪個 Candidate 的成功情境報酬
最好」。搜尋器的 B 部分其實是同一個口徑，只有兩點不同：

| | 現有產品 | 搜尋器 |
|---|---|---|
| 劇本從哪來 | 使用者自己填 | 分析師共識算出來 |
| 劇本長什麼樣 | 一個目標價（可選最好／最壞價位） | 一個價格帶，附成真機率 |
| 排名口徑 | 成功情境報酬 | **價格帶內的條件情境報酬**（同一口徑的區間版） |

所以搜尋器不必推翻現有定位。新增的是兩件事：「劇本由系統產生」，以及「劇本附上成真機率」。

## 2. 名詞（已收錄到 `CONTEXT.md`）

| 名詞 | 白話定義 |
|---|---|
| **Search Universe（搜尋範圍）** | 使用者選的標的集合，例如當日的美國前 500 大 |
| **Consensus Target（共識目標價）** | 仍有效的個別分析師 12 個月目標價的中位數 |
| **Target Dispersion（目標價分歧度）** | 個別目標價彼此差多少（標準化後可跨股票比較） |
| **Target Age（目標價新舊）** | 構成共識的目標價距今多久沒更新 |
| **Band Horizon（價格帶期間）** | 價格帶對準的那一個選擇權到期日，以距今天數表示。和劇本的月級 `target_month` 是不同的概念 |
| **Price Band（價格帶）** | 「某標的在某日期的股價會落在 L 到 U 之間」的一個預測，附成真機率 |
| **Band Probability（價格帶成真機率）** | 股價實際落在價格帶內的機率；必須是**歷史驗證過**的機率 |
| **Conditional Band Return（條件情境報酬）** | 假設股價落在價格帶內，一個選擇權組合的報酬範圍 |
| **Full Expected Value（完整期望值）** | 把價格帶內**和帶外**的所有結果都按機率加權後的平均報酬 |

**最重要的區分**：條件情境報酬只回答「**如果**落在帶內會怎樣」；完整期望值還要知道
「**沒**落在帶內時會虧多少、機率多少」。兩者不能混用（§5.4）。

## 4. A — 預測：從分析師共識到價格帶

### 4.1 共識特徵

對標的 *i*、日期 *t*，取當時仍有效的個別目標價 `TP₁…TP_N`：

| 特徵 | 公式 | 白話 |
|---|---|---|
| 共識目標價 | `TP = median(TPⱼ)` | 中位數，避開極端值 |
| 隱含漲幅 | `u = ln(TP / S₀)` | 分析師認為還能漲多少（取對數方便比較） |
| 分歧度 | `D = (TP 的四分位距) / S₀`；人數少時改用標準差 | 意見有多不一致 |
| 新舊 | `age` = 目標價中位數距今天數 | 目標價有多舊 |
| 人數 | `N` | |

### 4.2 為什麼不能直接拿目標價當價格帶

分析師目標價是**一個點**、期間固定為 **12 個月**、而且**平均偏樂觀**（見 `02-roast.md` P1）。
所以目標價只能當**線索**（特徵），不能直接當答案。

搜尋器的做法是：「過去**跟現在很像**的情況（相似的隱含漲幅、分歧度、新舊），股價後來
**實際上**落在哪裡？」——用歷史的**實際結果**來決定價格帶。分析師的樂觀偏誤因此會被歷史
結果自動校正：如果目標價平均高估，歷史分布自然會落在目標價下面。

### 4.3 價格帶怎麼算（最簡單的版本）

**① 準備歷史樣本**：每個歷史觀測記下特徵 `X = (u, D, age)`、預測期間 `h` 天、實際結果
`R = ln(S_{t+h} / S_t)`。

**② 找「相似情況」**：把 `u`、`D`、`age` 各分成三組（低／中／高），共 27 格。每一格收集
所有歷史結果 `R`。

**③ 取分位數**：價格帶的下緣與上緣，就是那一格歷史結果的分位數：

```
下緣 L = S₀ · exp( q_α(R | 該格) )
上緣 U = S₀ · exp( q_β(R | 該格) )
名目成真機率 = β − α
```

例：取 α = 10%、β = 90%，就是「過去相似情況裡，八成的結果落在這個區間」。

**④ 樣本不足時往全體靠攏**：某一格樣本少的時候，分位數不可靠。做法是和「不分格的全體
分位數」加權平均，樣本越少越靠全體：

```
q̂ = w · q_該格 + (1 − w) · q_全體，   w = n / (n + k)
```

`n` 是該格樣本數，`k` 是事先設定的常數（例如 200）。

**⑤ 機率要報保守值**：成真機率用**樣本外驗證**的實際命中率，並報信賴區間的**下界**
（Wilson 區間）。歷史上預測期間互相重疊，有效樣本數遠小於筆數，計算時要按日期分群。

**價格帶的兩種形式**

| 形式 | 定義 | 適用 |
|---|---|---|
| 單邊下緣 | `P(S_T ≥ L)`，例：「八成機率不低於 L」 | 看漲的單調結構（Long Call、Bull Call Spread）：下緣就決定最差情況 |
| 雙邊區間 | `P(L ≤ S_T ≤ U)` | 非單調結構（Butterfly）；或要封頂宣稱的最大收益時 |

**「高可信度」和「有用」互相拉扯**：區間開得越寬，機率越高，但對選擇權越沒用（例：
「股價會在 1 到 1000 之間」機率幾乎 100%，毫無價值）。所以驗證時要同時看兩件事：
**機率準不準（校準）**、**區間窄不窄（銳利度）**（見 `03-revised-plan.md` §3）。

### 4.4 預測期間與選擇權到期日對應

> 用詞：價格帶對準的是一個**到期日**（日級），稱為 **Band Horizon（價格帶期間）**。現有劇本刻意只有月級的
> `target_month`、`CONTEXT.md` 也禁止說「目標日期」；兩者是不同概念，劇本的語意不受影響（這個用詞衝突列為待決事項 D10）。

分析師目標價固定是 12 個月；選擇權到期日從幾週到兩年都有。規則：

1. **價格帶一律按「價格帶期間」重新估**：要配 90 天後到期的選擇權，就用歷史上**90 天後**的
   實際結果算價格帶。**不能**把 12 個月的目標價按比例縮放。
2. **預測期間的格點**：30／60／90／180／365 天，以及更長天期（若要配 LEAPS）。到期日不在
   格點上時，用最近的格點；兩個格點之間不插值（v1 刻意保持簡單）。
3. **兩種持有方式**：

| 方式 | 價格帶日期 | 計算 |
|---|---|---|
| 持有到期（預設） | 價格帶日期 ＝ 到期日 | 到期損益，純公式，**不需要 IV 假設** |
| 到期前出場 | 價格帶日期 ＜ 到期日 | 用現有引擎在該日期估部位價值，**需要 IV 假設**（沿用現有保守 IV 情境） |

4. **目標價的剩餘期間**：一個已經發布 8 個月的 12 個月目標價，只剩約 4 個月的「預言期」。
   這由新舊特徵 `age` 處理，不另外調整目標價本身。

### 4.5 看跌方向

同一套方法反過來：用上緣 `U` 搭配 `P(S_T ≤ U)`，產生 Long Put、Bear Put Spread 的機會。
分析師目標價低於現價的情況比較少，研究期可以先只做看漲，但產品不排除看跌。

## 5. B — 選擇權搜尋：機械化計算與排序

### 5.1 窮舉範圍

每個價格帶（標的 × 價格帶期間），在**對應到期日**上列出：

| 結構 | 窮舉方式 |
|---|---|
| Long Call／Long Put | 每個合格履約價 |
| Vertical Spread（Bull Call／Bear Put） | 每對（買腿、賣腿），寬度不超過使用者上限 |
| Butterfly | 現有引擎支援的組合 |

**剪枝**：只保留履約價落在價格帶附近（例如 `[0.8·L, 1.2·U]`）的組合。對看漲結構而言，履約價
遠高於 U 的合約在帶內一定歸零，可以先剔除，這樣不會漏掉任何「在帶內會賺錢」的組合。

### 5.2 成本與流動性（沿用現有規則）

- 成本用**最差可成交價**：買腿 ask、賣腿 bid，含手續費（現有引擎口徑）。
- 過濾：最低未平倉量、最大價差 %、**最低成本**（避免便宜合約讓報酬率爆炸，見
  `docs/research/option-liquidity-filtering.md` 的實測）、使用者條件（最大損失上限等）。

### 5.3 條件情境報酬（價格帶內）

對組合的到期損益 `Π(s)` 與成本 `C`：

| 指標 | 公式 | 白話 |
|---|---|---|
| 帶內最差報酬 | `r_min = min_{L≤s≤U} Π(s) / C − 1` | 只要股價落在帶內，**至少**賺（或虧）這麼多 |
| 帶內最佳報酬 | `r_max = max_{L≤s≤U} Π(s) / C − 1` | 帶內最好的情況 |
| 帶內損益兩平比例 | 帶內使 `Π(s) ≥ C` 的區間占比 | 帶內有多大範圍是賺錢的 |
| 最大損失 | `C` | Debit 結構 |

單調結構（Long Call、Bull Call Spread）的最小值與最大值一定出現在 `L` 和 `U`，直接代入即可；
非單調結構（Butterfly）要在帶內切格點掃描，不能只算兩端。

### 5.4 條件情境報酬 vs 完整期望值

只有價格帶與成真機率，**算不出**完整期望值，因為不知道帶外會發生什麼。最簡單、不加任何
模型的兩種補足：

**補足 1：期望值下界（只需要價格帶本身）**

買方結構的損益永遠 ≥ 0，所以帶外最壞就是損益歸零。對看漲的單調結構：

```
EV ≥ P(S_T ≥ L) × Π(L) − C
```

這是**嚴格成立的下界**，不需要任何額外假設。下界 > 0，就代表「即使帶外全部歸零，平均起來
仍然賺錢」。下界 ≤ 0 不代表期望值為負，只代表價格帶資訊不足以判斷。

**補足 2：歷史類比期望值（不需要新模型）**

§4.3 每一格本來就有完整的歷史結果樣本，直接拿來算平均損益：

```
EV ≈ (1/n) · Σ_k Π( S₀ · e^{R_k} ) − C
```

這是「過去相似情況真的發生的結果」套到今天的組合上，等於免費拿到整條分布。缺點是只在
樣本夠多的格子可信，所以只當**參考欄位**，不當主排序。

### 5.5 排序（排序規則是 Owner 的決策，見 `03-revised-plan.md` D3）

候選規則（可讓使用者切換）：

| 規則 | 做法 | 特性 |
|---|---|---|
| R-1 保守優先（老弟建議預設） | 先過濾成真機率下界 ≥ 門檻，再依 `r_min` 排序 | 回答「只要預測成立，哪個最穩」 |
| R-2 期望值下界 | 依 `EV 下界 / C` 排序 | 同時考慮機率與帶外歸零 |
| R-3 最大倍率 | 依 `r_max` 排序 | 最接近使用者直覺，但容易排出彩票型合約 |
| R-4 二維前緣 | 顯示（成真機率、`r_min`）的前緣，不壓成單一分數 | 最誠實，但較難一眼看懂 |

**同一標的不霸榜**：同一個價格帶的所有組合共用同一個成真機率，排序前幾名很容易都是同一檔
股票。輸出時每檔股票預設只顯示前 k 個組合。

### 5.6 數值示例（全部為假設值）

標的 XYZ：`S₀ = 100`，價格帶期間 180 天（對應那一天到期的月選）。

假設 A 部分給出：

| 價格帶 | 內容 |
|---|---|
| 單邊下緣 | `P(S_T ≥ 105) = 80%`（保守值，信賴區間下界） |
| 雙邊區間 | `P(105 ≤ S_T ≤ 130) = 70%` |

B 部分算出（成本為最差可成交價，示例）：

| 組合 | 成本 C | 帶內最差 `r_min`（S=105） | 帶內最佳 `r_max`（S=130） | EV 下界 | EV 下界 / C |
|---|---|---|---|---|---|
| Bull Call 95/105 | 6.00 | **+67%** | +67% | +2.00 | **+33%** |
| Bull Call 100/110 | 4.20 | +19% | +138% | −0.20 | −5% |
| Long Call 95 | 9.00 | +11% | +289% | −1.00 | −11% |
| Long Call 105 | 4.00 | −100% | **+525%** | −4.00 | −100% |

算法（Bull Call 95/105）：`Π(105) = min(105−95, 10) = 10`，`r_min = 10/6 − 1 = 67%`；
`EV 下界 = 0.8 × 10 − 6 = 2.0`。

**示例要表達的重點**

1. 用「最大倍率」排序（R-3），第一名是 Long Call 105（+525%）——但只要股價停在帶的下緣，
   它就**全虧**。
2. 用「保守優先」排序（R-1），第一名是 Bull Call 95/105：只要預測成立就賺 67%，而且即使帶外
   全部歸零，期望值下界仍然是正的。
3. 同一個價格帶，不同排序規則給出**完全相反**的建議，所以排序規則必須是明確的產品決策。

## 7. ETF 與其他市場（未來擴充，不在研究期）

- 股票型 ETF：可用成分股目標價加權成「由下而上目標價」；這個做法業界存在，但有已知的
  長期高估（見 `02-roast.md`）。價格帶仍然要用 ETF **自己**的歷史結果校準。
- 債券、商品、槓桿／反向 ETF：沒有對應的分析師目標價，**不硬套**；需要另一個價格帶來源。
- 這也是 §0「價格帶是唯一交接物」的好處：B 部分不必知道價格帶從哪來，換一個來源就能擴充。
