## 1. 產品目標

**一句話**：從美國市場裡找出「現在值得買入的選擇權」，依預估獲利機率、獲利倍率、
期望報酬與風險排序。重點是**選擇權本身值不值得買**，不是預測哪檔股票漲最多。

| 項目 | v0 構想 |
|---|---|
| 掃描母體 | 美國市值前 500 大上市公司＋約 100 檔大型或具代表性的 ETF |
| 排除 | 流動性不足、買賣價差過大的選擇權 |
| 候選結構 | Long Call、Long Put、Debit Spread（Bull Call／Bear Put） |
| 排序維度 | 獲利機率（POP）、獲利倍率、期望報酬（EV）、風險（最大損失、流動性、交易成本） |
| 持有方式 | 區分「持有到期」與「提前出場」兩種策略 |

**非目標（v0 就排除）**：自動下單、組合最佳化、個人化適合度（suitability）、Credit 策略
（賣方）、即時盤中訊號。

### 1.1 與現有 Option Chaser 的關係（已知衝突，交由炙烤處理）

現有產品的定位寫在 `CONTEXT.md` 的 **Scenario Bet Ranking**：使用者自己給價格劇本，
回答「如果我的劇本成立，哪個 Candidate 的成功情境報酬最好」；**失敗情境不是排名維度**、
**不是 risk-adjusted return**。

掃描器有兩個根本差異：

1. **劇本來源**：不是使用者給，而是由分析師共識自動產生。
2. **排序口徑**：要納入獲利機率、EV 與風險——正是現行定位明文排除的維度。

這是領域層級的衝突，v0 不先決定，見炙烤 R8 與修訂方案 D1。

## 2. 術語草案（未寫入 `CONTEXT.md`，待 Owner 確認後才收錄）

| 術語 | 定義（草案） |
|---|---|
| **Scanner Universe（掃描母體）** | 某一個掃描日可被掃描的標的集合（前 500 大個股＋約 100 檔 ETF）。必須是**當日**的成分，不是今天的成分回推。 |
| **Consensus Target（共識目標價）** | 某標的在某一時點、仍有效的個別分析師 12 個月目標價集合的中位數（或平均）。 |
| **Target Dispersion（目標價分歧度）** | 個別目標價的離散程度，標準化後可跨標的比較（公式見 §4.1）。 |
| **Implied Upside（隱含漲幅）** | 共識目標價相對現價的報酬：`TP / S₀ − 1`。 |
| **Target Age（目標價新舊）** | 構成共識的個別目標價距今多久沒更新。 |
| **Touch Hit（期間觸及達標）** | 在期間內任何一天收盤價曾達到目標價。 |
| **Terminal Hit（到期達標）** | 在期間最後一天收盤價達到目標價。 |
| **Model Distribution（模型分布）** | 由歷史條件式統計得到的「未來某日價格」機率分布（真實世界機率 P）。 |
| **Market-implied Distribution（市場隱含分布）** | 由選擇權報價反推的風險中立分布 Q。v0 **不**拿它當預測。 |
| **Opportunity（機會）** | 一個 Candidate 在 Model Distribution 下算出的 POP／EV／倍率／最大損失的組合。 |

## 3. 資料流

```
 ① 掃描母體（當日成分）
        │
        ▼
 ② 現價、選擇權鏈快照（bid/ask/size/OI/IV）── 流動性過濾 ──┐
        │                                                  │ 剔除
        ▼                                                  ▼
 ③ 分析師共識快照：TP 中位／平均、N、σ、分歧度、新舊        （不進入）
        │
        ▼
 ④ 篩選：N 太少、分歧過高、資料過時 → 剔除（門檻由歷史驗證決定）
        │
        ▼
 ⑤ 條件式機率模型：給定（隱含漲幅、分歧度、期間、市場環境）
    → 未來價格的 Model Distribution（不只單一目標價的達標率）
        │
        ▼
 ⑥ 候選產生：每檔 × 每個合格到期日 × {Long Call, Long Put, Debit Spread}
        │
        ▼
 ⑦ 期望值計算：用 Model Distribution 對到期損益積分；成本用市場報價（最差可成交價）
        │
        ▼
 ⑧ 排序與輸出：POP、倍率、EV、最大損失、流動性、成本
```

**資料需求一覽**

| 資料 | 用途 | 需要的歷史深度 |
|---|---|---|
| 歷史成分（S&P 500 等） | 避免存活者偏差 | 回測全期 |
| 個別分析師目標價＋發布日＋修訂紀錄 | ③④⑤ | 理想 2000 起（含 2000／2008／2020／2022） |
| 股價（含除權息、分割調整、下市報酬） | ⑤ 的結果變數 | 回測全期 |
| 歷史選擇權 EOD 報價（含 bid/ask） | ⑦ 的成本與回測損益 | 回測全期 |
| 即時選擇權鏈 | 上線後的 ②⑦ | 當日 |
| ETF 持股權重（若採成分加權） | D | 回測全期 |

## 4. 核心演算法

### 4.1 A — 分析師共識特徵

對標的 *i*、掃描日 *t*，取 *t* 當下仍有效（未過期、未被撤回）的個別目標價
`TP₁…TP_N`（12 個月期）：

| 特徵 | 公式 | 說明 |
|---|---|---|
| 共識目標價 | `TP_med = median(TPⱼ)`（或 `TP_mean`） | 中位數較抗極端值 |
| 分析師人數 | `N` | |
| 標準差 | `σ_TP = stdev(TPⱼ)` | |
| 標準化分歧度 | `D = σ_TP / S₀`（替代：`σ_TP / TP_mean`） | 用現價標準化較穩定，不受目標價本身高低影響 |
| 隱含漲幅 | `u = TP_med / S₀ − 1` | |
| 新舊 | `age = t − 最近更新日`（取中位數或最舊） | |

**核心假設 H1（待驗證，不是事實）**：`D` 越小，`u` 的預測越可靠。

**初步排除規則（門檻待歷史驗證決定，不預先鎖死）**：`N < N_min`、`D > D_max`、
`age > age_max`。

### 4.2 B — 成真機率模型（條件式）

**不**把市場 IV 換算成預測機率。改用歷史分析師紀錄建立條件式統計：

對每個歷史觀測（標的 *i*、日期 *t*）記錄特徵 `X = (u, D, N, age, h, regime)` 與結果：

- 期間報酬 `R_h = S_{t+h} / S_t − 1`，`h ∈ {30, 60, 90, 180, 365}` 天
- `TouchHit_h = 1[ max_{t<s≤t+h} S_s ≥ TP_med ]`
- `TerminalHit_h = 1[ S_{t+h} ≥ TP_med ]`（看跌情境方向相反）

**單一目標價的達標率**（分箱經驗頻率＋信賴區間）：

```
p̂_touch(bin)    = Σ TouchHit / n_bin
p̂_terminal(bin) = Σ TerminalHit / n_bin
95% CI：Wilson interval
```

分箱維度：`u` 分位 × `D` 分位 × `h` × `regime`（牛市／熊市／極端）。

**從「達標率」到「價格分布」**：v0 的構想是估計**條件式報酬分布**，而不只是單點：

```
F̂(r | X) = P(R_h ≤ r | X)
```

兩種實作候選：

1. **分箱經驗分布**：同一個箱子裡的歷史 `R_h` 直接當作分布樣本。
2. **分位數迴歸（quantile regression）**：對 τ = 0.05, 0.10, …, 0.95 估 `Q_τ(R_h | X)`，
   拼成整條分布。

有了 `F̂`，任何價位 *x* 的機率都能算：`P(S_T ≥ x) = 1 − F̂(x/S₀ − 1 | X)`。

### 4.3 C — 選擇權期望值

對每個候選（到期日 *T*、`h = T − t`），用 **Model Distribution** 對**到期損益**積分，
成本用**市場報價**（沿用現有產品的「最差可成交價」：買腿用 ask、賣腿用 bid）。

| 量 | 公式 |
|---|---|
| 成本（最大損失） | `C = Σ 買腿 ask − Σ 賣腿 bid`（含手續費） |
| 到期損益 | `Π(S_T)`：Call `max(S_T−K,0)`；Put `max(K−S_T,0)`；Spread 為兩腿差 |
| 期望報酬 | `EV = E_P[Π(S_T)] − C`；`EV% = EV / C` |
| 獲利機率 | `POP = P(Π(S_T) > C)` |
| 目標情境倍率 | `M = Π(TP_med) / C` |
| 最大損失 | `C`（Debit 結構） |

離散化計算：把 `F̂` 切成價格格點，`E_P[Π] ≈ Σ_k p_k · Π(s_k)`。

**區分兩種持有方式**

| 持有方式 | v0 計算 |
|---|---|
| 持有到期 | 上式，只需到期價格分布 |
| 提前出場（例：觸及目標價即賣出） | 需要**路徑**（何時觸及）＋**出場時的選擇權價格**（需 IV 假設）。v0 只列為需求，計算方法未定 |

**市場報價的角色**：只用來算買入成本 `C`。**不**用同一套 IV 模型的風險中立機率當作獨立的
預測優勢——因為 `E_Q[Π] ≈ C·e^{rT}`，拿 Q 算 EV 必然約等於 0，沒有資訊。

### 4.4 D — ETF

ETF 多半沒有完整的分析師目標價。v0 列出三個方向，**不預設採用哪一個**：

| 方案 | 做法 | 疑慮 |
|---|---|---|
| D-1 成分加權 | `TP_ETF = Σ wⱼ · TPⱼ / Sⱼ × S_ETF`（用權重加總成分股的隱含漲幅） | 覆蓋率、權重時點、非股票型 ETF 不適用 |
| D-2 另一套獨立預測 | 例如趨勢、估值或總經模型 | 等於另一個產品 |
| D-3 v1 先排除 ETF | — | 母體少 100 檔 |

**原則**：不得為了統一模型而強行套用不適合的資料。

### 5.2 輸出（每個機會一列）

| 欄位 | 說明 |
|---|---|
| 標的、結構、履約價、到期日 | 可下單的部位 |
| 成本 `C`、最大損失 | 最差可成交口徑 |
| POP | 模型分布下的獲利機率 |
| EV、EV% | 期望報酬 |
| 目標情境倍率 `M` | 達到共識目標價時的倍率 |
| 共識特徵 | `TP_med`、`u`、`N`、`D`、`age` |
| 模型可信度 | 該箱樣本數、信賴區間寬度 |
| 流動性 | 價差 %、OI、成交量 |

### 5.3 數值示例（全部為說明用假設值）

標的 XYZ：`S₀ = 100`，`TP_med = 120`（`u = 20%`），`N = 25`，`D = 0.08`，期間 180 天。

假設條件式模型給出的 180 天後價格分布（示例）：

| `S_T` | 80 | 90 | 100 | 110 | 120 | 130 | 140 |
|---|---|---|---|---|---|---|---|
| 機率 | 10% | 15% | 20% | 20% | 20% | 10% | 5% |

（此分布的期望價格為 107.5，低於目標價 120——符合文獻中目標價普遍偏樂觀的現象。）

| 候選 | 成本 C | E_P[Π] | EV | EV% | POP | 目標情境倍率 |
|---|---|---|---|---|---|---|
| Long Call K=110 | 4.00 | 5.50 | +1.50 | +37.5% | 35% | 10/4 = 2.5× |
| Bull Call 110/130 | 2.80 | 5.00 | +2.20 | +78.6% | 35% | 10/2.8 = 3.6× |

計算（Long Call）：`E_P[Π] = 20%×10 + 10%×20 + 5%×30 = 5.5`；`POP = P(S_T ≥ 120) = 35%`。

**示例要表達的重點**：只要模型分布 P 比市場定價 Q 更「看多」，EV 就會是正的。
**整個掃描器的價值，等於「P 比 Q 更準」這件事是否成立**——這正是炙烤要攻擊的核心。

## 6. 回測草案（v0）

1. 每月第一個交易日為掃描日，母體用**當日**成分。
2. 只用掃描日**當時已發布**的目標價（point-in-time）。
3. 用掃描日**之前**的資料估模型（walk-forward），算出每個候選的 POP／EV。
4. 依排序買入前 N 名，用當日 ask 成交，持有到期，記錄損益。
5. 檢驗：預測 POP 與實際勝率是否一致（校準）、前 N 名的實際報酬是否優於基準。
