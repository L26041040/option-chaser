## 3. 成功門檻（修正後；具體數字由 Owner 定，下列為老弟建議值）

所有門檻**事先登錄**，結果出來後不得修改。研究用**時間切分**：前段估模型、後段驗證，
例如 2021–2023 估、2024 之後驗證。

| # | 門檻 | 怎麼量 | 建議值 |
|---|---|---|---|
| G1 校準 | 驗證期實際命中率 vs 標示機率 | 按日期分群的命中率＋bootstrap 信賴區間 | 點估計落在標示值 ±5 個百分點內，且信賴區間包含標示值 |
| G2 銳利度 | 分析師版本 vs 波動度基準 | 同樣命中率下的平均區間寬度（% of S₀），或分位數損失（pinball loss） | 寬度至少窄 5%，或損失較低，且 bootstrap 信賴區間不含 0 |
| G3 逐期揭露 | 每個年度、2022 空頭期間分別報告命中率 | 表格 | **揭露項目，不是門檻**（除非 Owner 另訂下限） |
| G4 期間分級 | 每個預測期間分別判定 | G1、G2 逐期間檢驗 | 只有通過的期間才在產品上顯示機率 |

**刪除的第一輪門檻**：「打贏同天期隨機選擇權」「不劣於股票」「t ≥ 3.0」（理由見 `02` §0）。
股票比較保留為**參考報告**。

分位數損失（評估區間預測的標準指標）：

```
ρ_τ(y, q) = (τ − 1[y < q]) · (y − q)
```

越小越好，同時懲罰「太寬」與「太常落在區間外」。

## 4. 停損條件（修正後）

| 情況 | 結論 | 後續（Owner 決定，見 D2） |
|---|---|---|
| G1 在所有期間都不通過（校準後在驗證期仍漂移） | 這套方法給不出可信的機率 | 暫停 A；不對使用者顯示機率 |
| G1 通過、G2 不通過 | 機率可信，但分析師資料沒有加分 | 可用**波動度價格帶**上線，或繼續研究分析師特徵 |
| G1、G2 都通過 | 分析師價格帶成立 | 進入產品化 |

**不再停損的情況**：選擇權組合沒有打贏股票、沒有打贏隨機選擇權——這些不是預測品質問題。

## 5. 最低成本、可逐步擴展的驗證方案

每一階段都只在前一階段過關後才花下一筆錢或時間。

| 階段 | 做什麼 | 需要的資料 | 金錢成本 | 過關條件 |
|---|---|---|---|---|
| S0 資料盤點 | 抽樣 30～50 檔，確認目標價有發布日、每檔每月筆數、能否看到被撤回的目標價；確認歷史指數成分來源 | FMP 試用或最低方案、日線股價 | 低（最多一個月平價方案；價格待查） | 每檔每月平均 ≥ 3 筆有效目標價，發布日可用 |
| S1 波動度基準 | 只用股價，做出波動度價格帶，量 G1 | 日線股價、指數成分 | 幾乎為零 | 基準本身校準良好（G1） |
| S2 分析師價格帶 | 加入 `u`、`D`、`age`，比較基準（G2），檢驗排除門檻（H4） | S0 的目標價歷史 | 同 S0 | G1＋G2（依 G4 逐期間） |
| S3 B 部分空跑 | 拿當天的即時選擇權鏈，對 5～10 檔跑完整窮舉、計算、排序，人工核對結果 | 即時選擇權鏈（現有 Provider） | 現有成本 | 計算正確（§6），排序結果可解釋 |
| S4 擴大 | 全部 S&P 500；更多期間；開始累積自有目標價快照 | 同上 | 視規模 | Owner 決定 |
| S5 選配 | 若要驗證 2008、2020：機構級資料（I/B/E/S 等）；ETF 價格帶 | 機構資料 | 高，需另行報價 | Owner 決定 |

**為什麼這樣排**：S1 幾乎免費，而且 S1 本身就是一個能用的價格帶來源；即使 S2 失敗，S3 的
B 部分也能接 S1 的價格帶上線。

## 6. B 部分的驗收（工程正確性，不是研究）

| 項目 | 驗收方式 |
|---|---|
| 損益正確 | 單腿、Spread、Butterfly 的到期損益與現有引擎一致（重用既有原語） |

| 期望值下界 | 只對 Debit 結構計算；手算示例一致（設計 §5.6） |

| 排序 | 每種排序規則有固定輸入與預期輸出；同標的霸榜限制生效 |

## 8. 仍未解決的研究問題

1. 平價 API 的目標價是否保留**被撤回**或**被改寫**的紀錄——S0 要確認。
2. 歷史指數成分的可靠免費來源——S0 要確認。
3. 2021 年後只有一次空頭（2022）；這段樣本代表不了 2008、2020，只能誠實揭露或走 S5。
4. 365 天期間在研究期只有約 4～5 段互不重疊的期間，統計上很弱——暫不宣稱。
5. 到期日落在兩個預測格點之間時，v1 用最近格點；插值方法留待日後。
6. 引用的學術數字多停在摘要層級，S2 結論發表前要讀全文複核。
