MOBILE PRINCIPLE

* Stack the same sections vertically.
* Do not remove decision-critical financial information.
* Compress whitespace, titles and repeated labels.
* IV charts should remain compact sparklines.
* Do not create a second Heatmap for crossover comparison.

CROSSOVER SEMANTICS

For every future state (t, S):

Spread Return(t, S)
Comparator Return(t, S)

Boundary condition:

Spread Return(t, S) = Comparator Return(t, S)

One side:

Comparator Return > Spread Return

Other side:

Spread Return > Comparator Return

Important:

* The boundary is not one scalar crossover point.
* Do not assume the boundary is straight.
* Do not force monotonic behavior.
* If the calculated line bends, breaks, or leaves the visible grid,
    render the actual result.
* Do not label every cell WIN / LOSE.
* The existing Spread return values remain the main Heatmap values.
* The crossover line is an overlay.
