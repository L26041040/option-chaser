### 我要的是：

> **寧可沒有 Logo，也不要假 Logo。**

## Logo API 候選

目前我知道至少有以下候選，你可以自行研究，也可以找到更好的方案：

### Brandfetch
https://brandfetch.com/developers/logo-api

它有 stock / ETF ticker 對應品牌資產的能力。

### Logo.dev
https://www.logo.dev/products/stock-ticker-logos

它也提供 ticker → company logo 的 API。

但請特別注意：

如果任何 API 在找不到真實 Logo 時會自動回傳：

- monogram
- ticker initials
- generated placeholder
- generic icon

那種 fallback **不是我要的結果**。

如果 API 有辦法辨認「真實 Logo」與 fallback，
我們只接受真實 Logo。

你也可以自行研究其他：

- 免費 API
- 有足夠免費額度的 API
- open dataset
- reliable company-brand source

不限制一定使用 Brandfetch 或 Logo.dev。
